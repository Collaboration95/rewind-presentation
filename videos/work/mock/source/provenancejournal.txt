OPEN / RECORD
Serve the mock directory as a static localhost directory; keep assets/, source/, states/ together.
Open photo.html or video.html in the parent's simulator Safari, then begin recording during the 5-second opening hold.
Each camera page has a 46-second timeline plus the default 5-second initial delay: 51 seconds from readiness. It holds the final ledger indefinitely; it does not loop.
The stage is 402 x 714 CSS pixels, scaled to the actual content viewport. Native Safari chrome is provided by Safari, not baked into these pages.
?delay=0 removes the initial delay. ?delay=10 gives ten seconds to start recording.
?pause&at=7&delay=0 holds a selected timeline time for inspection. window.rewindSeek(seconds) changes the timeline. ArrowRight advances to the next state. R reloads the camera timeline.
The cloned look/shutter/record buttons and the screenshot Seal hotspot can advance the timeline. Automatic timing is the default and needs no taps.
Main camera pages and their frames make only same-origin static requests. No sign-in is required.
